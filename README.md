# API статей

Вариант 4. Express и Mongoose, сущность Article: `title` (обязательное), `content` (обязательное), `author`. Эндпоинт `/api/articles`.

Строка подключения лежит в `.env` (`MONGO_URI`). Если по ней сервер не отвечает, процесс поднимает встроенный MongoDB, чтобы CRUD можно было проверить без отдельной установки.

## Запуск

```bash
npm install
npm start
```

Для разработки с перезапуском: `npm run dev`.
